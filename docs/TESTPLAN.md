## Notes for Stakeholder Review

- The current implementation manages one in-memory balance for one running session.
- The current implementation enforces insufficient-funds protection for debits.
- The current implementation does not include student identifiers, transaction history, audit logging, or persistent storage.
- The current implementation should also be reviewed for input validation requirements, because the business logic currently focuses on menu routing, balance updates, and overdraft prevention.
